# BLACKOUT

Mobile-first logic/arcade game experiment.

## Core loop

Rotate network tiles to reconnect power from SOURCE to TARGET before the grid collapses.

## Goals

- understandable in seconds
- short 30–120s sessions
- logic + reflex
- playable for free
- optional rewarded ads / IAP later
- one codebase for web, Android and iOS

## Milestone

Vertical Slice 0.1: playable browser prototype, several levels, score, stars and progression.
