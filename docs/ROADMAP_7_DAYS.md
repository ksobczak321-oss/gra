# BLACKOUT — 7 day launch roadmap

## Day 1 — prove the core loop
- playable mobile web prototype
- 5 handcrafted sectors
- rotation, connectivity, win detection
- moves / par / stars
- persistent local progression
- basic visual identity

Exit criterion: a new player understands the game without explanation and can finish a level.

## Day 2 — retention loop
- 20–30 levels
- tutorial without text walls
- difficulty curve
- daily challenge shell
- streak and best-score storage
- fail/retry feedback

Exit criterion: 10–15 minutes of varied play without feeling repetitive.

## Day 3 — feel and identity
- sound effects
- haptics
- animated power pulse
- improved transition / completion effects
- icon, logo and first store key art
- first marketing hooks for Meta creatives

Exit criterion: gameplay looks good in a 5–10 second vertical video.

## Day 4 — mobile packaging
- move project into a Vite + Capacitor structure
- Android package / application ID
- Android API 36 target
- iOS project shell
- analytics events
- crash reporting
- rewarded-ad and IAP interfaces behind feature flags

Exit criterion: installable Android build from the same gameplay codebase.

## Day 5 — store readiness
- privacy policy
- support page
- Google Play listing copy
- screenshots
- feature graphic
- content rating inputs
- data safety inventory
- QA matrix for common Android aspect ratios

Exit criterion: release candidate can be uploaded to Google Play Console.

## Day 6 — test + acquisition experiment
- internal / closed testing release
- 3–5 Meta ad concepts
- web landing/play page
- install/play CTA split
- instrumentation for ad click -> game start -> level completion

Exit criterion: complete acquisition funnel is measurable.

## Day 7 — release candidate
- fix test feedback
- tune first-session difficulty
- tune rewarded-ad placement
- final store assets
- production submission when account eligibility allows it

## Monetization rules

BLACKOUT should remain fully playable without purchases.

Initial monetization candidates:
1. rewarded ad after a loss: optional extra move / hint,
2. rewarded ad for one daily bonus,
3. small one-time Remove Ads purchase,
4. cosmetic themes / power-core skins,
5. later: inexpensive mission pack.

No forced ad after every level. No artificial hard paywall in the core campaign.

## Initial Meta marketing hypothesis

Creative should show the puzzle immediately rather than explain the fiction.

Hooks to test:
- "Only 4 moves. Can you see it?"
- "99% rotate the wrong tile first."
- "Restore the grid before it goes dark."
- deliberately almost-solved board with one visible mistake

The ad itself should function as a mini puzzle: pause on a board state, invite the viewer to choose the move, then show the satisfying solution.

## Future merchandise direction

Only after validating retention / audience affinity:
- LED desk puzzle / network lamp inspired by the grid,
- physical card/puzzle set with BLACKOUT circuits,
- shirts / hoodies only if visual identity gains organic traction.

Do not invest in inventory before product-market signal exists.
