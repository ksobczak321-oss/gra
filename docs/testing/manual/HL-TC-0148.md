| Pole | Wartość |
|---|---|
| Typ | Ręczny odbiór v31 |
| Obszar | Wykonalność misji |

| Stan definicji | READY |
| Wynik ręczny | **NOT RUN — nie wykonano** |
| Powiązane zmiany | [HL-CHG-1083](../../tracking/changes/HL-CHG-1083.md), [HL-CHG-1116](../../tracking/changes/HL-CHG-1116.md) |
| Środowisko | DEV 0.14.0.0 / v31 po integracji; wpisz rzeczywisty SHA i cache. PRE-PROD 0.13.1.0 nie zalicza tej próby. |

## Dane i warunki

Nowy profil oraz kopie stanów z brakującym poziomem, obsadą, zasobem i pojemnością.

Używaj izolowanego profilu QA i adaptera lub fikstury. Nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, usługi lub danych oznacza **BLOCKED**, nie PASS.

## Kroki i oczekiwane wyniki

1. **Czynność:** Otwórz bieżący etap oraz informacje o przygotowaniach.

   **Oczekiwany wynik:** Aktywny jest tylko bieżący cel. Gracz widzi rzeczywiste braki i dostępne sposoby ich uzupełnienia.

2. **Czynność:** Spróbuj przyjąć cel z brakującym odblokowaniem lub nierealnym czasem dostawy.

   **Oczekiwany wynik:** Problem jest wyjaśniony przed terminem i nieodwracalną wpłatą. Gra nie obiecuje wykonania niedostępnej czynności.

3. **Czynność:** Przejdź przygotowanie bez reklamy, ligi i cudzej oferty handlowej.

   **Oczekiwany wynik:** Istnieje osiągalna droga lokalna. Raportuj brak takiej drogi jako FAIL, a brak potrzebnych danych jako BLOCKED.

## Raport wykonania

- Tester, data, rzeczywisty SHA/cache i środowisko: do uzupełnienia.
- Dane, założenia i ograniczenia: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
