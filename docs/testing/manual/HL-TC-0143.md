| Pole | Wartość |
|---|---|
| Typ | Ręczny odbiór i regresja v30 |
| Obszar | Podziwianie ogrodu |
| Priorytet | P1 |
| Stan definicji | READY |
| Wynik ręczny | **NOT RUN — nie wykonano** |
| Powiązane zmiany | [HL-CHG-1077](../../tracking/changes/HL-CHG-1077.md) |
| Środowisko | DEV 0.13.1.0/v30; zapisz rzeczywisty SHA i cache. Brak domniemania promocji PRE-PROD. |

## Dane i warunki

Użyj izolowanego profilu lub kontrolowanej fikstury z zapisanym Teatrem. Brak wymaganej usługi, kontroli zegara, odpowiedniego buildu lub fikstury oznacza **BLOCKED**, nie PASS. Nie resetuj ani nie podmieniaj historii admin1–admin3. Rzeczywistych płatności i reklam nie zastępuj fikcyjnym potwierdzeniem; w DEV używaj jawnej symulacji.

## Kroki i oczekiwane wyniki

1. **Czynność:** Ustaw kilka dekoracji i wybierz Podziwiaj ogród.

   **Oczekiwany wynik:** Znikają siatka, zaznaczenia i narzędzia edytora. Widać aktualną kompozycję i światło.

2. **Czynność:** Wybierz Wróć do aranżowania i porównaj kolekcję, saldo i rozmieszczenie.

   **Oczekiwany wynik:** Narzędzia wracają; kompozycja, poziomy, własność i saldo pozostają.

3. **Czynność:** Powtórz oba tryby na telefonie i komputerze oraz po zmianie atmosfery.

   **Oczekiwany wynik:** Widok pozostaje czytelny; przycisk powrotu jest dostępny i nie trzeba resetować studia.

## Raport wykonania

- Tester, data, rzeczywisty SHA/cache i środowisko: do uzupełnienia.
- Fikstura, język i rozmiar ekranu: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
