## Dane i warunki

Adapter opóźniający ACK oraz aktywny ładunek lub scena przestawiania.

Używaj izolowanego profilu QA i adaptera lub fikstury. Nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, usługi lub danych oznacza **BLOCKED**, nie PASS.

## Kroki i oczekiwane wyniki

1. **Czynność:** Wykonaj kilka szybkich różnych ruchów przed pierwszym ACK.

   **Oczekiwany wynik:** Dozwolone ruchy sceny są przyjęte, a nie odrzucone wyłącznie przez zwykły zapis.

2. **Czynność:** Odtwórz starsze ACK, utracone ACK i obcą rewizję na oddzielnych kopiach.

   **Oczekiwany wynik:** Starsze ACK nie cofa sceny; konflikt przyjmuje potwierdzony postęp i nie powiela nagrody.

3. **Czynność:** Sprawdź czas próby i wypłatę przy przerwie połączenia.

   **Oczekiwany wynik:** Uzgodniona ochrona czasu działa; nie można podwójnie wydać lub odebrać monet.
