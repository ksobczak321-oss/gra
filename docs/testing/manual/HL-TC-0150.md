# HL-TC-0150 — Cena rekrutacji odświeża się przed startem i jest spójna po akceptacji

|---|---|
| Typ | Ręczny odbiór v31 |

| Stan definicji | READY |
| Wynik ręczny | **NOT RUN — nie wykonano** |
| Powiązane zmiany | [HL-CHG-1085](../../tracking/changes/HL-CHG-1085.md) |
| Środowisko | DEV 0.14.0.0 / v31 po integracji; wpisz rzeczywisty SHA i cache. PRE-PROD 0.13.1.0 nie zalicza tej próby. |

## Dane i warunki

Misja przygotowana przy Ratuszu 3; kontrolowane zasoby na koszt przed i po awansie.

Używaj izolowanego profilu QA i adaptera lub fikstury. Nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, usługi lub danych oznacza **BLOCKED**, nie PASS.

## Kroki i oczekiwane wyniki

1. **Czynność:** Awansuj Ratusz przed przyjęciem przygotowanej misji.

   **Oczekiwany wynik:** Oferta przed startem pokazuje aktualną cenę i dokładny brak.

2. **Czynność:** Przyjmij misję, potem zmień poziom lub wznów grę przed zakupem.

   **Oczekiwany wynik:** Misja oraz powiązany zakup używają tej samej uzgodnionej ceny.

3. **Czynność:** Wykonaj operację i odtwórz utracone ACK w adapterze testowym.

   **Oczekiwany wynik:** Zaliczenie i pobranie występują raz. Kolejne potwierdzenie nie powoduje ponownej opłaty.

## Raport wykonania

- Tester, data, rzeczywisty SHA/cache i środowisko: do uzupełnienia.
- Dane, założenia i ograniczenia: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
