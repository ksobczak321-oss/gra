## Dane i warunki

Użyj izolowanego profilu lub kontrolowanej fikstury z zapisanym Teatrem. Brak wymaganej usługi, kontroli zegara, odpowiedniego buildu lub fikstury oznacza **BLOCKED**, nie PASS. Nie resetuj ani nie podmieniaj historii admin1–admin3. Rzeczywistych płatności i reklam nie zastępuj fikcyjnym potwierdzeniem; w DEV używaj jawnej symulacji.

## Kroki i oczekiwane wyniki

1. **Czynność:** Otwórz dobrowolne inspiracje i zapisz saldo, listę własności oraz poziomy.

   **Oczekiwany wynik:** Widać wskazówki dotyczące nastroju, rodzajów i stylów, bez oceny urody lub rankingu.

2. **Czynność:** Wybierz kolejno dwie różne inspiracje i ustaw własną mieszaną kompozycję.

   **Oczekiwany wynik:** Inspiracja nie dokonuje zakupu i nie narzuca kompletnego układu. Gracz może łączyć pomysły według własnego gustu.

3. **Czynność:** Zmień inspirację i przestawiaj tę samą ozdobę kilkukrotnie.

   **Oczekiwany wynik:** Nie powstaje kara ani nieograniczona premia monet lub szczęścia.
