# HL-TC-0191 — Po otwarciu budynku wskazuj dokładną kontrolkę

| Pole | Wartość |
|---|---|
| Typ | Ręczny odbiór zadań i planisty Doradcy |
| Obszar | Nawigacja wewnątrz menu |
| Priorytet | P0 |
| Stan definicji | READY |
| Wynik ręczny | **NOT RUN — nie wykonano** |
| Powiązane zmiany | [HL-CHG-1186](../../tracking/changes/HL-CHG-1186.md) |
| Środowisko | Kandydat DEV0.15.3.1/cache23 albo nowe PRE-PROD tego samego źródła po pełnym odbiorze; wpisz rzeczywisty SHA. Odebrane fc95/cache22 nie zalicza tej próby. |

## Dane i warunki

Używaj izolowanego profilu QA i kontrolowanej fikstury. Nie resetuj ani nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, wersji, danych lub dowodów oznacza **BLOCKED**, nie PASS. Testy automatyczne nie zapisują ręcznego wyniku.

## Kroki i oczekiwane wyniki

1. **Czynność:** Po wskazaniu na mapie sam otwórz budynek i przewiń menu do zadania.

   **Oczekiwany wynik:** Wskazówka prowadzi do dokładnej kontrolki bez jej naciskania i bez przesłaniania.

2. **Czynność:** Zamknij menu, otwórz inne, zmień zadanie i ponownie otwórz właściwy budynek.

   **Oczekiwany wynik:** Nie ma strzałki do usuniętego lub obcego elementu; po powrocie wskazywana jest bieżąca kontrolka.

## Raport wykonania

- Tester, data, rzeczywisty SHA/cache i środowisko: do uzupełnienia.
- Dane, ograniczenia i rzeczywisty przebieg: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
