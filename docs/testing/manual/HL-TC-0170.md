## Dane i warunki

Konto QA z dwiema wyspami i rozpoczętym oknem godzinowym.

Używaj izolowanego profilu QA i adaptera lub fikstury. Nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, usługi lub danych oznacza **BLOCKED**, nie PASS.

## Kroki i oczekiwane wyniki

1. **Czynność:** Zagraj, wypłać lub przegraj, następnie rozpocznij nową serię w tym samym oknie.

   **Oczekiwany wynik:** Licznik i wynikająca z niego trudność nie restartują przez samą nową serię.

2. **Czynność:** Wznów konto i przełącz wyspę przed resetem.

   **Oczekiwany wynik:** Pozostaje ten sam stan konta. UI pokazuje czas i wyjaśnia reset.

3. **Czynność:** Przekrocz kontrolowaną granicę okna z aktywną serią.

   **Oczekiwany wynik:** Nowe okno jest spójne; należna nagroda trwającej serii nie znika ani nie jest powielona.
