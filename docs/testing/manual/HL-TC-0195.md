## Dane i warunki

Używaj izolowanego profilu QA i kontrolowanej fikstury. Nie resetuj ani nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, wersji, danych lub dowodów oznacza **BLOCKED**, nie PASS. Testy automatyczne nie zapisują ręcznego wyniku.

## Kroki i oczekiwane wyniki

1. **Czynność:** Sprawdź zapis w środku tutoriala i zachowanego ukrytego kursu, używając izolowanych kopii QA.

   **Oczekiwany wynik:** Tutorial ma nadal 28 kroków; kurs25 pozostaje ukryty bez kasowania lub rozliczania postępu i nagród.

2. **Czynność:** Przed testem PRE-PROD odczytaj rzeczywiste źródło, wersję i nowe dowody standardowej promocji oraz kont przed/po.

   **Oczekiwany wynik:** Brak nowego źródła lub wymaganych dowodów oznacza BLOCKED; dawne fc95 nie jest PASS nowej wersji. QA nie resetuje kont i nie zmienia zegara.

- Dane, ograniczenia i rzeczywisty przebieg: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
