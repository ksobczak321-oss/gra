# HL-TC-0127 — Trzy rzeczywiste konta widzą katalog bez formularzy i bez ujawniania prywatnych danych

| Pole | Wartość |
|---|---|
| Typ | Ręczny odbiór i regresja v29 |
| Obszar | Katalog społeczności |

| Powiązane zmiany | [HL-CHG-1063](../../tracking/changes/HL-CHG-1063.md) |
| Środowisko | DEV0.13.0.0/v29; wpisz rzeczywisty SHA/cache. PRE-PROD0.12 nie zawiera automatycznie nowej paczki. |

## Dane i warunki

QA-COMMUNITY29: izolowany rzeczywisty serwerAPI z trzema kontami odpowiadającymi admin1–admin3i zachowanymi światami; osobno brak świata i trybPROD. Użyj izolowanego profilu/harnessu QA; nie resetuj ani nie podmieniaj historii admin1–admin3. Brak danych, kontrolowanego zegara lub usługi oznacza **BLOCKED**, nie PASS.

## Kroki i oczekiwane wyniki

1. **Czynność:** Zaloguj pierwszą osobę i otwórz czat bez zapisywania trzech pseudonimów.

   **Oczekiwany wynik:** Katalog udostępnia dwie pozostałe istniejące osoby; nie są to tożsamości pertabdemo.

2. **Czynność:** Zmień pseudonim, zaloguj ponownie i porównaj prywatny zapis wyspy przed/po.

   **Oczekiwany wynik:** Wybrana nazwa pozostaje; sam katalog nie przepisuje świata, poziomów lub środków.

3. **Czynność:** Sprawdź odpowiedźAPI i wariant bez świata/PROD.

   **Oczekiwany wynik:** Brak UID, e-maili, haseł i zasobów; brak wymyślonego konta bez świata, brak automatycznej rejestracji pseudonimuPROD.

## Raport wykonania

- Tester, data, rzeczywisty SHA/cache i środowisko: do uzupełnienia.
- Fixture, język i rozmiar ekranu: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
