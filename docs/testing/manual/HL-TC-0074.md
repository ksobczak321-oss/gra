| Typ | Ręczny przypadek testowy; nie zgłoszony incydent |

| Wynik ręczny | **NOT RUN — nie wykonano** |
| Powiązane zmiany | [HL-CHG-0983](../../tracking/changes/HL-CHG-0983.md), [HL-CHG-0987](../../tracking/changes/HL-CHG-0987.md) |
| Środowisko | DEV 0.12.0.0/v28; rzeczywisty build/SHA do zapisania. PRE-PROD 0.11 pozostaje bez nowej promocji. |

## Dane i warunki

QA-PICKUP28: kurs 6 lekcja 11, producent z pełnym składem, wolni ludzie i odrębne warianty wolnej/pełnej centrali.

Użyj izolowanego konta/świata QA i kontrolowanego harnessu. Nie resetuj ani nie podmieniaj historii `admin1`–`admin3`. Brak fixture, zegara, właściwego buildu lub wymaganej usługi oznacza **BLOCKED** z przyczyną. Nie zmieniaj prawdziwej bazy ani zegara urządzenia w celu wymuszenia warunku. Automatyzacja nie zastępuje wykonania ręcznego.

## Kroki i oczekiwane wyniki

1. **Czynność:** Otwórz opis Gospodarstwa, Drwali, Kamieniołomu, Młyna i Tartaku.

   **Oczekiwany wynik:** Każdy wskazuje smutną buźkę, tragarzy, priorytet odbioru, lekcję 11 i miejsce w centrali.

2. **Czynność:** Przejdź lekcję 11 od mapy.

   **Oczekiwany wynik:** Wskazówki prowadzą do rzeczywistego dodatkowego tragarza oraz właściwych szczegółów/priorytetu odbioru.

3. **Czynność:** Uruchom odbiór przy wolnej centrali.

   **Oczekiwany wynik:** Faktyczny ładunek jedzie do centrali i odblokowuje producenta; samo kliknięcie priorytetu nie tworzy towaru.

4. **Czynność:** Powtórz przy pełnej centrali.

   **Oczekiwany wynik:** Opis nie obiecuje nieograniczonego przyjęcia. Brak miejsca jest czytelny i nie pobiera opłaty za niewykonalną usługę.

5. **Czynność:** Obejrzyj ofertę natychmiastowego odbioru za monety.

   **Oczekiwany wynik:** Instrukcja nie nazywa tragarzy jedynym sposobem; wycena i kontrola miejsca są zgodne.

## Raport wykonania

- Tester i data: do uzupełnienia.
- Faktyczny build/SHA, adres, środowisko i tryb zapisu: do uzupełnienia przed startem.
- Fixture oraz wariant PL/EN i komputer/telefon: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Uzyskane wartości i dowody bez tokenów: do uzupełnienia.
- Numer błędu albo powód BLOCKED: do uzupełnienia.
