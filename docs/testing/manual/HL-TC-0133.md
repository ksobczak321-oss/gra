# HL-TC-0133 — Pełna gra rozlicza reklamę dekoracji i dodatkowej belki bez fałszywej nagrody

|---|---|
| Typ | Ręczny odbiór i regresja v29 |
| Obszar | Reklamy w przygodach |
| Priorytet | P0 |
| Stan definicji | READY |

| Powiązane zmiany | [HL-CHG-1049](../../tracking/changes/HL-CHG-1049.md), [HL-CHG-1050](../../tracking/changes/HL-CHG-1050.md), [HL-CHG-1056](../../tracking/changes/HL-CHG-1056.md) |
| Środowisko | DEV 0.13.0.0/v29; wpisz rzeczywisty SHA/cache. PRE-PROD 0.12 nie zawiera automatycznie tej paczki. |

## Dane i warunki

Izolowana gra DEV z dekoracją poziomu 4, monetami, aktywną budową mostu i oznaczoną symulacją reklamy. Oddzielna lokalna konfiguracja PROD bez dostawcy. Brak wymaganej fikstury, kontroli zegara lub usługi oznacza **BLOCKED**, nie PASS. Nie resetuj ani nie podmieniaj historii admin1–admin3.

## Kroki i oczekiwane wyniki

1. **Czynność:** W Teatrze rozpocznij ulepszenie do poziomu 5, a następnie pomiń film.

   **Oczekiwany wynik:** Cena była widoczna, ale poziom i saldo nie zmieniają się. Nie pojawia się potwierdzenie prawdziwej reklamy.

2. **Czynność:** Ponów ulepszenie i obejrzyj cały oznaczony film DEV.

   **Oczekiwany wynik:** Dokładnie jeden poziom i jedno obciążenie monet; po powrocie ta sama zmiana jest widoczna w Teatrze i na mapie.

3. **Czynność:** W przygodzie mostu pomiń, a następnie ukończ reklamę dodatkowej belki.

   **Oczekiwany wynik:** Pominięcie nic nie przyznaje. Pełny film daje dokładnie jedną belkę; podstawowy zestaw nadal wystarcza bez filmu i zakupu.

4. **Czynność:** Odśwież stronę w trakcie filmu i spróbuj ponowić stare potwierdzenie. Powtórz bez dostawcy w konfiguracji PROD.

   **Oczekiwany wynik:** Przerwany film nie ma nagrody. Stare potwierdzenie nie działa drugi raz. PROD nie przyjmuje klientowego verified=true jako dowodu dostawcy ani nie udaje wyświetlenia reklamy.

## Raport wykonania

- Tester, data, rzeczywisty SHA/cache i środowisko: do uzupełnienia.
- Fikstura, język i rozmiar ekranu: do uzupełnienia.
- Wynik: **NOT RUN**; po wykonaniu PASS / FAIL / BLOCKED.
- Oczekiwane/uzyskane, dowód bez tokenów i numer błędu: do uzupełnienia.
