## Dane i warunki

QA-TRADE: dwa różne syntetyczne UID A/B z Ratuszem 6 i zapasem wymienianych materiałów; serwerowe API wymian w izolowanej bazie. Jeżeli API PRE-PROD nie jest potwierdzone jako aktywne, oznacz BLOCKED. Baseline v22.1: NPC wyłączone dla nowych zleceń odTH6.

Brak przygotowanego, odizolowanego fixture lub brak dostępu do wskazanego trybu oznacza BLOCKED, a nie PASS.

Konta `admin1`–`admin3` nie są jednorazowymi fixture. Zgoda na osobny reset po promocji nie jest zgodą na dowolne resetowanie, manipulację zegarem lub podmianę ich danych podczas testów. Ten przypadek nie uruchamia skryptu resetu właściciela.

## Kroki i oczekiwane wyniki

1. **Czynność:** Sprawdź dostępność handlu na TH5 i TH6; opublikuj z A ofertę 100 drewna za 100 kamienia.

   **Oczekiwany wynik:** OdTH6 w baseline nowe oferty NPC są zastępowane wymianą graczy. A rezerwuje towar na serwerze raz; cudzy UID nie jest ujawniony jako publiczna nazwa gracza.

2. **Czynność:** Spróbuj przyjąć tę samą ofertę równocześnie z B i drugim odrębnym kontem testowym albo powtórzyć to samo żądanie.

   **Oczekiwany wynik:** Tylko jedno przyjęcie skutkuje wymianą; ponowienie nie daje drugich towarów. Nie można przyjąć własnej oferty.

3. **Czynność:** Anuluj inną ofertę albo rozlicz jej wygaśnięcie przy pełnym magazynie właściciela.

   **Oczekiwany wynik:** Zwrot zachowuje materiały i bonusową ewidencję; niemieszcząca się część czeka w trwałej skrzynce. Sam GET listy nie pobiera ani nie oddaje towarów. Nowy modelNPC+PvP ma odrębny DRAFT 37.
