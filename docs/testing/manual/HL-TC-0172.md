# HL-TC-0172 — Łap ładunek rozlicza pojedynczy klik bez duplikatów

## Dane i warunki

Aktywna scena ładunku, opóźniony zapis, mysz i dotyk.

Używaj izolowanego profilu QA i adaptera lub fikstury. Nie podmieniaj historii admin1–admin3. Brak właściwej implementacji, usługi lub danych oznacza **BLOCKED**, nie PASS.

## Kroki i oczekiwane wyniki

1. **Czynność:** Kliknij jedną sztukę raz, potem szybko kilka innych.

   **Oczekiwany wynik:** Każdy celny dozwolony klik zbiera właściwą sztukę; podwójny klik nie jest wymagany.

2. **Czynność:** Spróbuj ponownie wskazać już zebrany przedmiot.

   **Oczekiwany wynik:** Nie powstaje dodatkowa nagroda za tę samą sztukę.

3. **Czynność:** Dokończ, wznów grę i rozlicz wynik.

   **Oczekiwany wynik:** Nagroda odpowiada faktycznym złapaniom oraz jawnej regule budżetu.
