# HARBORLIGHT — Game Concept

## Product thesis

A mobile-first game with two connected loops:

1. **Logic / expedition puzzles** — short, thoughtful levels with multiple valid solutions and scoring for speed, efficiency and creativity.
2. **Settlement / economy meta-game** — build a peaceful island settlement with production chains inspired by classic settlement builders, but without PvP attacks.

The core promise is that puzzle progress directly powers settlement growth, and settlement needs determine which puzzles matter next.

## World

The player restores a storm-damaged island around an old lighthouse.

Long-term objective: rebuild the lighthouse in 7 stages, restoring the island district by district. Completing the first island unlocks additional islands/biomes with new production chains and puzzle mechanics.

## Loop A — Expedition puzzles

Puzzles are small, visual terrain dioramas rather than abstract line-connection boards.

Examples:

- get a supply cart across a river with limited planks and rope,
- move rocks to create a route through a ravine,
- use a fallen tree as a bridge or take a longer detour,
- open gates in the correct order,
- route workers through a compact maze while collecting optional resources,
- use limited tools in different combinations to reach the objective.

Levels should have multiple valid solutions.

### Puzzle scoring

Score can combine:

- completion time,
- number of actions,
- number/value of tools used,
- route length,
- optional resource pickups,
- bonus objectives,
- efficiency versus a reference solution.

This allows casual completion and mastery play on the same level.

## Loop B — Island settlement

The island is not purely decorative. Buildings create real production dependencies.

### Example production chains

**Wood**
Forest -> Lumber Camp -> Logs -> Sawmill -> Planks -> Carpenter -> Houses / Barns / Upgrades

**Food**
Field -> Grain -> Mill -> Flour -> Bakery -> Food -> Population growth

**Animals**
Barn -> Pasture -> Cows / Pigs -> Milk / Meat -> Market / Kitchen

**Stone / construction**
Quarry -> Stone -> Mason -> Blocks -> Roads / Harbor / Lighthouse

**Clay / advanced construction**
Clay Pit -> Kiln -> Bricks -> Advanced buildings

## Population

Population provides workers.

More production requires more workers, while population growth requires housing and food. This creates a lightweight economic constraint without combat.

Possible later mechanics:

- worker assignment,
- building adjacency bonuses,
- storage limits,
- seasonal production changes,
- ecological constraints such as forest regrowth,
- trade ship orders.

## Critical connection between both loops

Puzzles must not feel like a disconnected mini-game.

The settlement creates concrete needs.

Example:

Player wants a Sawmill -> needs 8 stone + Sawmill blueprint -> game offers quarry expedition -> player completes 2–3 terrain puzzles -> returns with stone and blueprint -> builds Sawmill -> plank production starts -> new buildings become possible.

The intended emotional loop is:

**Need -> Expedition -> Puzzle -> Reward -> Build -> Visible growth -> New need**

## Lighthouse progression

The old lighthouse is the main chapter progression object.

Each reconstruction stage can:

- visually transform the island,
- unlock new land,
- unlock a new production chain,
- unlock new puzzle mechanics,
- introduce new residents,
- increase harbor reach to another island.

## First playable MVP

The MVP should validate whether the two loops reinforce each other.

Scope:

- 1 island,
- 6 buildable structures,
- 3 production chains,
- simple inventory,
- simple worker/population count,
- 8–10 expedition puzzles,
- at least 2 valid solutions for several puzzles,
- puzzle rewards that are immediately spendable in the settlement,
- persistent browser save,
- one visible lighthouse upgrade milestone.

## Initial buildings

Suggested first six:

1. Lumber Camp
2. Sawmill
3. House
4. Field
5. Mill
6. Bakery

The lighthouse exists as a chapter objective rather than a normal building.

## Monetization direction

The game must remain playable for free.

Potential non-blocking monetization later:

- rewarded ad for a bonus expedition chest,
- rewarded ad to instantly finish one production batch,
- cosmetic island/building themes,
- decorative packs,
- optional premium construction queue,
- seasonal cosmetic pass,
- convenience currency without locking core progression.

Avoid forced ads during puzzle solving.

## Marketing hook

Creative should show both loops in one short ad:

1. player solves a clever terrain puzzle,
2. receives a missing resource/blueprint,
3. immediately cuts to the island where a new building rises,
4. new production starts and the settlement visibly grows.

Message example:

**Solve the expedition. Build the island. Watch every choice change your world.**

## Current decision

BLACKOUT and PANIC PETS were mechanic experiments. HARBORLIGHT becomes the current product direction for the next prototype.
