# Arkusz zasad HARBORLIGHT

[Pobierz Excel — HARBORLIGHT-zasady.xlsx](https://github.com/ksobczak321-oss/gra/raw/refs/heads/main/docs/arkusze/HARBORLIGHT-zasady.xlsx)

Jeżeli przeglądarka pokazuje stronę pliku na GitHubie, wybierz **Download raw file**. Pobrany plik można otworzyć w Excelu lub LibreOffice Calc albo zaimportować do Arkuszy Google.

Arkusz zawiera 11 zakładek: główną tabelę 12 budynków i assetu Człowiek, kartę człowieka, 92 pozycje ustaleń i uwag, komentarze w komórkach, kalkulator transportu i budowy, parametry, otwarte decyzje, demografię, przystań, odłożone błogosławieństwa i oryginalne źródło.

Nowsze ustalenia zastępują wcześniejsze wartości. Limit zatrudnienia jest opisany jako połowa maksymalnej populacji ratusza, z ograniczeniem do faktycznie wolnych ludzi. Estymaty czasu obejmują tylko transport i budowanie. Ceny portowe wynoszą za 100 sztuk: podstawowe 40/50, przetworzone 70/80. Nowe zasady błogosławieństw pozostają odłożone.

Plik to dokument projektu. Udostępnienie arkusza nie zmienia kodu, zasad ani zapisów działającej gry.
